# Lista 2 de Inteligência Artificial — 2026.2

Repositório com as implementações das questões práticas da segunda lista de exercícios da disciplina de Inteligência Artificial do curso de Ciência da Computação da Universidade Federal de Alagoas (UFAL), ministrada pelo Prof. Evandro Costa.

## Questões implementadas

| Questão | Tema |
| --- | --- |
| 02 | K-Nearest Neighbors (KNN) |
| 06 | Lógica fuzzy — controle de irrigação |
| 07 | Diagnóstico médico baseado em casos |
| 08 | Diagnóstico médico com redes bayesianas |
| 09 | Sistema de recomendação baseado em ontologias |
| 10 | Algoritmos de busca e planejamento de rotas |
| 12 | Agente baseado em LLM |
| 15 | Ontologia acadêmica em OWL 2 |

## Instalação e execução

Requisitos: Python 3.10+ e Java 11+ (questões 9 e 15).

```bash
python -m pip install -r requirements.txt
```

Cada questão possui uma pasta própria com os códigos, resultados e instruções de execução. A demonstração padrão da questão 12 utiliza um backend simulado.
